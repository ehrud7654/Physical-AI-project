# 그리퍼 개폐폭 마커 신호 — 판정

폰 카메라 영상만으로 그리퍼 개폐폭을 얻는다. **별도 센서(포텐셔미터 등)는 쓰지 않는다.**

## 결론

- 개폐폭은 그리퍼 손가락에 붙인 **마커**를 영상에서 검출해 얻는다.
- 마커는 **패턴 없는, 꽉 찬 검은 정사각형 16mm**. 레일 연결부에 좌우 1개씩.
- ArUco 는 쓰지 않는다. 초점 FIXED 흐림에서 내부 패턴 판독이 0% 이고, 테두리 안이 비어
  있어 덩어리 검출로도 열등하다 (같은 코드로 ArUco D 86% vs 검은 사각형 D 97%).
- 마운트는 카메라를 뒤로 뺀 iPhUMI 식. 접근·파지·들어올림 전 구간에서 마커 가림이 없다.
- 초점은 **FIXED** 유지 (AUTO 보다 검출이 낫다).

## 검출 방법

앱은 이미지만 저장하고, 개폐폭은 **후처리 스크립트**(`tools/gripper_gap.py`)가 뽑는다.

1. adaptive threshold → 컨벡스 헐로 덩어리 면적 계산 (얇거나 끊어진 검은 테두리를 메움)
2. 같은 높이의 끊긴 조각은 병합, 화면 좌우 가장자리·세로 슬롯은 배제
3. **고정 마운트 제약**: 폰이 그리퍼에 고정이라 두 마커의 중점 x 가 화면 중앙에 고정된다
   (실측 ≈319px, std 3px). 이 중심선을 통과하는 대칭 쌍만 유효로 본다.
4. 레일식이라 좌우 손가락이 대칭 이동하므로, **한쪽 마커만 보여도** 중심선 대칭으로
   반대쪽을 복원한다 (아래 status M).

프레임별 검출 품질을 `status` 로 남긴다: `D` 양쪽 직접 / `M` 중심선 대칭 추정 /
`T` 템플릿 보강 / `X` 실패.

## 판정 (rec_20260903_192233, 492프레임 16.4초, FIXED)

| 기준 | 결과 | |
|---|---|---|
| 마커 크기 | 73~90px | 통과 |
| 양쪽 직접 검출(D) | **97%** | 통과 |
| 유효 프레임(D+M+T) | **100%** (실패 0) | 통과 |
| 평탄구간 잔차 95% | **1px** | 통과 |
| 기준점 교차검증 | 독립 검출과 일치 | 통과 |

물리적 가림은 한 프레임도 없었다. ArUco 대비 모든 항목에서 낫고, "두 마커 동시 검출"
기준도 실제로 넘겼다.

## 남은 것

- **px→mm 캘리브레이션**: 완전 개방·완전 닫힘에서 손가락 간격을 자로 실측 → 선형 변환.
  레일이라 선형이다. 확정 전까지 gripper.csv 는 `gap_px` 만 채운다.
- **좌우 대칭성 실물 확인**: 개폐 시 중점이 몇 px 움직였다. 백래시 수준인지 확인.
- **빠른 동작 재검증**: 이 판정은 보통 속도 녹화 기준. 더 빠른 동작에서 모션블러 재확인.
