# S.S.A.F.Y 프론트엔드 실행 안내

## 준비물

- Node.js 22.13 이상
- pnpm 10 이상
- Chrome, Edge 등 최신 웹 브라우저

별도의 데이터베이스, 환경 변수, 서버 계정은 필요하지 않습니다.

## 처음 실행하기

저장소를 받은 뒤 터미널에서 최상위 `FE` 폴더로 이동하고 다음 명령을 실행합니다.

```bash
pnpm install
pnpm run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. 기본 주소는 다음과 같습니다.

```text
http://localhost:3000
```

로그인 화면에는 확인용 아이디와 비밀번호가 미리 입력되어 있습니다. `로그인` 버튼을 누르면 모든 화면을 살펴볼 수 있습니다.

## 확인할 수 있는 기능

- 학습 데이터 선택 및 영상 미리보기
- Skill 이름과 로봇 선택
- 학습 진행률, 현재 단계, 예상 시간, 로그 및 완료 화면
- UMI, VLM, 모터 제어, 반복 블록 조립
- 모터별 각도 범위 설정
- 작업 저장 및 실행 상태
- 사용자별 로봇 접근 권한 관리

## 배포용 빌드 확인

```bash
pnpm run build
```

오류 없이 완료되면 배포 가능한 상태입니다.

## 현재 구현 범위

이 프로젝트는 UI 검토용 와이어프레임입니다. 화면의 사용자, UMI 데이터, 로봇, 학습 진행 상태는 샘플 데이터이며 실제 서버 API에는 아직 연결되어 있지 않습니다.

주요 화면과 샘플 데이터는 `app/page.tsx`, 전체 스타일은 `app/globals.css`에 있습니다. 서버 API가 확정되면 샘플 배열과 화면 상태를 API 응답으로 교체하면 됩니다.

`.openai/hosting.json`의 프로젝트 정보는 기존 비공개 미리보기 사이트용입니다. 로컬 실행에는 영향을 주지 않으며, 별도 사이트로 게시할 때는 새 프로젝트 설정을 사용해야 합니다.

## 폴더 안내

```text
FE/
├─ app/
│  ├─ page.tsx        # 화면과 상호작용
│  ├─ globals.css     # 전체 디자인
│  └─ layout.tsx      # 제목과 공유 정보
├─ public/            # 이미지와 아이콘
├─ .openai/           # Sites 게시 설정
├─ package.json       # 실행 명령과 패키지 정보
└─ TEAM_SETUP.md      # 이 문서
```

`node_modules`, `dist` 등 생성 폴더는 Git에서 제외합니다. `pnpm install`을 실행하면 필요한 패키지가 다시 생성됩니다.
