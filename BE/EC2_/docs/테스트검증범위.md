# 테스트 검증 범위 (BE/EC2_)

실행: `./gradlew test` (Docker 필요 — Testcontainers가 `postgres:17-alpine`, `redis:7-alpine`을 띄운다).
Docker 없는 환경은 `TEST_POSTGRES_URL / TEST_POSTGRES_USER / TEST_POSTGRES_PASSWORD / TEST_REDIS_HOST / TEST_REDIS_PORT`로 외부 인스턴스를 지정한다.

## 검증 항목 ↔ 테스트

| 검증 | 완료 기준 | 테스트 |
|---|---|---|
| 데이터 유지 | PostgreSQL·Redis 재시작 후 유지 | `scripts/verify-compose-persistence.ps1` (수동, Compose 볼륨·AOF) |
| 빈 DB migration | V1~V8 전체 적용 성공, 테이블 28개·부분 UNIQUE 인덱스·VLM 객체 부재 확인 | `migration/FlywayMigrationIntegrationTest.emptyDatabaseMigratesFullyAndRerunIsNoop` |
| migration 재실행 | 재호출 시 적용 0건, validate 성공, seed 행 수 불변 | 같은 테스트 + `migratingV1FirstThenTheRestProducesSameSchema` |
| 제약조건 | FK·UNIQUE·CHECK 위반을 SQLSTATE·constraint 이름으로 거부 | `schema/UniqueConstraint…`, `CheckConstraint…`, `ForeignKeyConstraint…IntegrationTest` |
| JPA 매핑 | `ddl-auto=validate` 통과 + persist→flush→clear→재조회 | `SsafyApplicationTests.contextLoads` + 도메인별 매핑 테스트 |
| Redis | 저장·조회·TTL 만료, lease Lua, Stream 재생 | `common/redis/RedisInfrastructureIntegrationTest`, `CommonConfigIntegrationTest` |
| 트랜잭션 | 업무 변경·Outbox 함께 커밋/롤백, 외부 트랜잭션 참여 | `event/OutboxTransactionIntegrationTest` |

## 공통 환경

- `support/container/SharedTestContainers` — JVM당 1회 기동, 모든 컨텍스트가 공유. Ryuk이 JVM 종료 시 정리.
- `support/IntegrationTestBase` — `@SpringBootTest @ActiveProfiles("test")`, `@Transactional` 없음.
- `src/test/resources/application-test.properties` — Compose 자동 실행·Outbox scheduler 비활성, key prefix `test:ssafy`.
- 격리 규칙: JPA 매핑·제약 테스트는 `@Transactional` 롤백, Outbox·동시성 테스트는 생성한 ID 기준 삭제, Redis 테스트는 테스트별 UUID 키 삭제. 통합 테스트 병렬 실행은 끈 상태(Gradle 기본).
