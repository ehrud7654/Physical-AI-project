# PM 역할 수행 내역

## 협업 규칙 설정 및 관리

깃 컨벤션, 브랜치 규칙, 지라 규칙을 정하고 운영했습니다. 상세 내용은 노션에 정리돼 있습니다.

- 커밋 메시지 형식과 타입 구분
- 브랜치 명명 규칙과 병합 흐름, 보호 설정
- 지라 이슈 계층·제목 규칙·라벨, 완료 기준 작성 방식
- 깃 관리 및 지라 전체 관리

## 작업 우선도 설정

하드웨어가 완성되거나 서버가 나오기전에도 개발을 진행할 수 있게 고려하여 작업의 우선도를 설정하였습니다. 

또한 최대한 빠르게 수행해야 하는 업무들 부터 선별하여 요청하였습니다.


## 당일 작업 내용 문서화 및 공유

그날 진행한 작업을 정리해 팀에 공유하는 규칙을 설정했습니다.

Keep·Problem·Try 형식으로 회고를 남기고 팀에 공유하는 규칙을 설정했습니다.
