# UMI 로봇팔 작업 학습 플랫폼 기능명세서

- 버전: 0.1.0 · 작성일: 2026-08-27
- 상태: 구현 전 초안. 중요도는 개발 범위 합의를 위한 제안이며 구현 완료 여부가 아니다.
- 기준 문서: [API 명세서](api-specification.md). 관련 API ID의 요청·응답·오류 상세는 해당 문서를 따른다.
- 기존 API 상세는 보존하고 기능 설명·완료 기준·중요도를 표로 재구성했다.

## 1. 중요도 기준

| 중요도 | 의미 | 적용 기준 |
|---|---|---|
| **P0 · 필수** | MVP 핵심 또는 보안·안전 필수 | 없으면 데이터 수집 → 학습 → 모델 적용 흐름이나 접근 통제가 성립하지 않음 |
| **P1 · 주요** | 운영·사용성·복구 기능 | 기본 흐름 이후 우선 구현. 수동 처리나 기존 API 조합으로 일시 대체 가능 |
| **P2 · 확장** | 추가 사용 경험·선택 범위 | MVP 이후 구현 가능. 도입 시 필수 의존 기능도 함께 구현 |
| **P2*** | 선택 영역 안의 필수 의존 기능 | 로봇 작업 실행을 도입하는 출시 범위에서는 검증·상태 확인·중지를 생략할 수 없음 |

| 구분 | 적용 원칙 |
|---|---|
| MVP 완료 범위 | 로그인 → UMI 연결 → 시연 업로드·검증 → 학습 요청·상태 조회 → 산출물 등록 → Jetson 배포·적용 확인 |
| Scratch 범위 | 앞선 API 초안과 동일하게 선택 기능. MVP 필수로 확정하면 관련 P2 기능을 P0로 재분류 |
| 사전 등록 | MVP 회원 계정·Jetson은 운영자가 등록 가능하다고 가정. 공개 회원가입·로봇 셀프 등록은 필수 범위에서 제외 |
| 실시간 표시 | SSE 도입 전에는 상세 조회 API를 주기적으로 호출하여 상태 표시 |
| 안전 | 웹 실행 기능의 우선순위와 무관하게, 물리 로봇 운용 시 로컬 안전 제어는 필수 |
