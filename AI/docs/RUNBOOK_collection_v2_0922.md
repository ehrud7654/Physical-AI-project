# 시연 수집 매뉴얼 v2 — 구운감자 집어서 상자에 넣기

2026-09-22 · 트랙 B 김준태 · **v1에서 바뀐 곳: 매핑 절차 전면 추가**

---

## 0. 왜 v2가 필요한가 — 한 장 요약

9/22에 31편을 찍었는데 **학습에 못 쓴다.** 촬영 품질은 전부 통과였다.
문제는 그다음 단계였다.

```
매핑 영상        정상 통과 (63초, 태그 985프레임, 정렬 오차 10.9mm)
시연 31편        영상 품질 전부 통과
SLAM 재국지화     31편 중 2~3편만 통과
  게다가 통과한 편도 좌표가 1.17m씩 순간이동했다
  프로그램은 "추적 성공"이라고 보고하면서
```

**원인**: 흰 책상·똑같은 의자가 반복되는 배경이라 SLAM이 다른 곳을 같은 곳으로
착각했다. 그리고 매핑 영상이 시연에서 카메라가 보는 범위를 다 담지 못했다.

**그래서 v2의 핵심은 두 가지다.**

```
① 배경에 서로 다른 무늬를 놓는다        착각할 곳을 없앤다
② 매핑에 시연 전 범위를 담는다          상자 위까지 포함
③ 2편 찍고 SLAM 먼저 확인한다          전멸을 두 번 하지 않는다
```

## 1. 준비 — 촬영 전 10분

### 1-1. 배경 만들기 (제일 중요해졌다)

작업대 주변에 **서로 다르게 생긴 물건**을 4~6개 놓는다.

```
놓을 것    책 · 가방 · 필통 · 노트북 · 머그컵 · 무늬 있는 천 · 신문지
놓을 곳    작업대 양옆 · 상자 뒤 · 로봇 반대편
```

- 붙일 필요 없다. **올려두기만** 하면 된다
- 단, **시연 내내 안 건드린다.** 하나라도 움직이면 그 편은 버린다
- 흰 테이블의 빈 면을 덮는 게 목적이다. 빈 흰색이 SLAM에 제일 나쁘다

### 1-2. 테이프로 표시

```
□ 물체 기준 위치       무작위로 놓을 때의 중심
□ 상자 위치            고정. 수집 중 안 옮긴다
□ 손 시작 지점
□ 포즈 기준점          기준 클립용
```

### 1-3. 건드리지 말 것

```
□ 테이블 태그(ID 13)   위치 고정. 치워야 하면 테두리를 테이프로 따놓고 복귀
□ 핸들·폰 마운트        분해 금지
□ camera_tcp 설정      그대로
```

### 1-4. 적어둘 것

```
□ 감자 폭 (넓은 면 / 좁은 면)    자로 재서
□ 상자 크기
□ 날짜 · 시각 · 장소
```

## 2. 공간 매핑 촬영 — 여기가 성패를 가른다

**목표**: "예쁜 지도"가 아니라 **"시연에서 보게 될 장면을 전부 담는 것"**.

### 2-1. 경로

빈손으로, 물체를 집지 않고, 카메라만 들고 아래 경로를 훑는다.

```
태그 정면 3~5초
  ↓
손 시작 지점
  ↓
물체 놓일 자리 위        ← 시연과 같은 높이·각도로
  ↓
파지 높이
  ↓
리프트 높이
  ↓
상자 위                  ← 9/22에 이게 빠졌을 가능성이 높다
  ↓
시작 지점으로 복귀
  ↓
태그 다시 3~5초
```

한 바퀴 더: **가까이(30cm) 한 번, 멀리(1m) 한 번.**

### 2-2. 어떻게 움직이나

**제자리에서 손목만 돌리지 마라.**

```
나쁨   한 자리에 서서 손목만 까딱
좋음   20~30cm씩 옆으로 옮기면서 같은 대상을 본다
       작업대 주위를 걸어서 돈다
```

왜: SLAM은 카메라가 실제로 움직여야 거리를 계산할 수 있다.
제자리 회전만 하면 깊이 정보가 안 생겨서 지도가 얇아지고, 나중에 재국지화가 깨진다.

**속도: 초당 15도 이하 (천천히)**

왜: 노출이 6.7ms라 더 빨리 돌리면 화면이 흐려져서 특징점을 못 잡는다.
계산하면 16도/초가 한계다. 참고로 실제 시연이 4~7도/초니까 그보다는 빠르게 해도 된다.

**길이: 90~150초**

9/22에는 63초였고 부족했다.

### 2-3. 매핑 체크리스트

```
□ 태그를 시작과 끝에 확실히 담았다
□ 상자 위까지 담았다
□ 제자리 회전이 아니라 이동하면서 찍었다
□ 시작 지점으로 돌아와서 끝냈다 (루프 닫기)
□ 가까이·멀리 두 번 돌았다
□ 사람이 지나가는 순간이 없었다
□ 90초 이상
```

## 3. 파일럿 2편 — 건너뛰지 마라

**매핑이 좋은지는 매핑만 봐서는 모른다.** 9/22 매핑은 모든 수치가 통과였는데
시연이 전멸했다. 매핑의 진짜 성공 기준은 **"시연이 재국지화되는가"** 다.

```
1. 시연 2편만 찍는다 (아래 4번 절차대로)
2. SLAM 돌린다
3. tracking 이 끝까지 유지되는지 본다
4. 프레임 간 좌표 점프가 없는지 본다
5. 통과하면 나머지 수집. 안 되면 2번(매핑)부터 다시
```

**5분이면 된다.** 이거 안 하면 9/22를 반복한다.

## 4. 시연 촬영 — 편마다 반복

```
① 감자를 무작위 위치에 놓는다
     좌우 ±30mm · 전후 ±20mm      기준 테이프 중심에서
     넓은 면(48mm)이 그리퍼를 향하게. 매 편 같은 자세
     회전은 주지 않는다
     ★ 순서대로(좌→중→우) 놓지 마라. 진짜 무작위로
     ★ 편 번호와 위치를 종이에 적는다

② 핸들을 80mm 로 벌리고 시작

③ 접근 — 80mm 유지한 채 감자 옆까지

④ 파지 — 손가락이 감자에 닿아 저항이 느껴질 때까지 확실히 조인다
     ★ 여유를 남기지 마라. 로봇이 그 여유를 그대로 배워서 놓친다

⑤ 든다

⑥ 상자 위로 옮긴다
     ★ 드는 순간부터 손목을 상자 쪽으로 향해 상자가 화면에 들어오게
     ★ 매 편 같은 각도로

⑦ 80mm 로 열어 놓는다   ★ 여는 폭도 규약이다

⑧ 편당 12~15초. 일정한 속도로
```

**바뀌는 것은 감자 위치 하나뿐이다.**

실패했으면 **앱에서 실패로 표시해라.** 9/22에 의도한 것보다 실패가 하나 더 있었다.

## 5. 20편에서 한 번 끊는다

```
20편 → 전처리 → check_collection.py → 판정 → 통과하면 나머지
```

판정 기준 (9/21 배치 70편 실측 대비)

| 항목 | 기준 |
|---|---|
| 접근 개구 중앙 | 70.4 ±3 mm (핸들 물리 80mm) |
| **파지 개구 중앙** | **≤ 40 mm** (감자 48 − 기록 오프셋 9 + 여유 1) |
| 편 길이 중앙 | 9 ~ 18 s |
| 마커 검출률 중앙 | ≥ 0.80 |
| outcome | 실패 편은 제외 |

**파지 개구가 40mm보다 크면 ④를 덜 조인 것이다.** 9/22 로봇 실험에서 정책이
43.0mm에서 멈춰 감자를 놓쳤고, 그 여유는 시연에서 온 것이다.
