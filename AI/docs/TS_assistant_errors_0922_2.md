## J1. 검색 범위를 좁게 잡고 "없다"를 답으로 받을 뻔했다

학습에 쓴 zarr 을 찾으려고:

```bash
find ~ -maxdepth 6 -type d -name "*.zarr"
```

`-type d` 라 **디렉터리 형태만** 봤다. 공식 UMI 는 `dataset.zarr.zip` **파일**로 저장한다.
결과로 `v4.zarr` 하나(76편)만 나왔는데, 찾던 것은 94편짜리다.

**편수가 안 맞는 걸 보고 범위를 의심한 것이 유일한 방어였다.** 규칙은 이미 있다 —
*"검색 0건이면 범위가 완전한지 먼저 본다"*. 1건도 마찬가지다.

사용자가 *"까먹은거야? 어제오늘한건데 또찾아?"* 로 지적했다. 기억의 문제가 아니라
**명령의 문제**였고, 그 구분을 내가 먼저 말했어야 했다.

→ **추가 규칙: `find` 에 `-type` 을 걸 때는 그 타입이 아닌 형태가 있는지 먼저 생각한다.**
   데이터셋은 디렉터리일 수도 zip 일 수도 있다.

**결국 옳았던 방법**: 학습 `config.yaml` 의 `dataset_path` 를 읽었다. **탐색이 아니라 기록.**
경로는 앞으로도 이렇게 확정한다.

## J2. 계측기가 "없음"과 "0프레임"을 같은 출력으로 냈다 — 서명 결함 재현

```python
def grasp_index(w, tol=0.005, hold=5):
    wmin = w.min()
    for i in np.nonzero(w <= wmin + tol)[0]: ...
```

개구가 **전혀 안 변하면** `wmin == w[0]` 이라 첫 인덱스가 조건을 통과해 **`0` 을 돌려준다.**
"파지 없음"과 "0프레임에 파지"가 구분되지 않는다.

**자체검증의 판별행이 잡았다** (`2 안닫힘 -> None` FAIL, 자체검증 2/3 → 수치 미산출).

중요한 점: 이 함수는 **앞선 세 개의 측정에서 이미 쓰였다.** 그때 미판정 0 이 나온 것은
하류 가드(`gi < 5`, `cs is None`)가 걸러줬기 때문이지 함수가 옳아서가 아니었다.
**가드에 의존한 계측기는 옳은 계측기가 아니다.**

→ 수정: `if (w.max() - w.min()) < min_range: return None` 을 함수 안에 넣었다.
   앞선 수치는 영향 없음(해당 편이 0건)을 확인하고 그대로 둔다.

→ **추가 규칙: 퇴화 입력(변화 없음·길이 0·전부 동일)의 반환값을 함수 자신이 책임진다.**
   호출부 가드로 덮지 않는다.

## J3. 서로 다른 양을 비교해 틀린 비율을 발표했다

*"명령 대비 실제 11%"* 라고 말했다. 실제로는

```
명령: 사이클별 순이동의 합 (= 경로장)
실제: 전체 구간의 직선 순이동
```

**경로장과 직선거리를 나눴다.** 구불구불하기만 해도 같은 비율이 나온다.

같은 단위로 다시 재니 **0.95 / 0.67** 이었다. 결론이 정반대로 바뀌었다
("실행부가 10배 깎는다" → "실행부는 깎지 않는다").

0922 전반 §정정-2 와 **같은 유형**이다 — 회전 불변량으로 회전을 재려 했던 것.
**양의 종류를 맞추지 않고 나눈 것.** 3주 사이 두 번째다.

→ **추가 규칙: 비를 낼 때 분자·분모가 같은 종류의 양인지 한 줄로 적고 시작한다.**
   (경로장/경로장, 직선/직선. 섞지 않는다)

## J4. 스윕을 성립하지 않는 가정 위에 설계했다

액션 → 테이블 변위의 **상수 회전**을 Kabsch 로 적합했다. 자체검증 3/3 통과.
그런데 **잔차 RMS 5.4~5.8mm 가 신호 크기(4.5~5.1mm)와 같았다.**

원인: 액션 각 행에 `rot6d` 회전이 들어 있어 **스텝마다 TCP 자세가 돈다.**
사이클당 상수 회전 가정이 애초에 성립하지 않는다. 데이터를 보기 전에 알 수 있었다 —
액션 열 구성(pos3 + rot6d + gap)은 문서에 적혀 있다.

**다행히 사전에 "잔차 크면 판정 불가"를 게이트에 박아둬서 76~111° 라는 숫자를
결론으로 쓰지 않았다.** 게이트가 없었으면 "90도 회전 확정"이라고 말했을 것이다.

→ **추가 규칙: 계측기의 가정이 데이터 표현과 모순되지 않는지 먼저 확인한다.**
   회전이 포함된 표현에 상수 회전을 적합하지 않는다.
