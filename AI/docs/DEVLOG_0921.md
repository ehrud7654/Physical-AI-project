## 2. 촬영 품질 게이트 재교정 🟢

`gate_raw_capture.py` 를 115편에 돌렸다.

```
통과 102 · 불합격 13 · 미판정 0 / 전체 115
권고 미충족 110 / 115   ← 폐기 사유가 아니다
```

### 필수/권고 분리 — 어시스턴트 오류에서 나온 변경

초판은 **프레임 수 상한을 필수로** 걸었고, 그 결과 **92편 전부 불합격**이 나왔다.
그 데이터는 현석이 학습에 성공시킨 배치였다. 상한은 "길어서 재현이 어려울 수 있다"는
경고이지 탈락 사유가 아니다.

분리 후 89/3 (3.3%) 이 됐고, 오늘 115편에서는 102/13 이다.

⚠️ **이 실수는 하루 전 `gate_slam_batch.py` 에서 이미 한 번 고쳤던 것**이고,
같은 수정을 `gate_raw_capture.py` 로 옮겨오지 않아 반복됐다.

### 판별행 보강

자체검증 9행 → 13행. 추가한 것:

- `3b` 250프레임 → 권고만 미충족, 판정은 PASS (정답 아는 행)
- `3d` 영상 크기 미지정 → **미판정**, PASS 아님
- `3e` 영상 없음 → 불합격 (미판정과 갈린다)
- `3c` 50프레임 → 하한 필수 불합격

`3d` 와 `3e` 를 가른 것이 핵심이다. **"파일이 없어서 못 쟀다"와 "재서 불합격"은 다른 상태**인데
초판은 둘 다 같은 출력이었다.

## 3. `episode_start_trim_s` 기본값이 파지 순간을 지운다 🟢

수정   trim 0.0   그리퍼 닫힘 검출 10 / 10 편

```

```

## 7. VLM 재정의 — D-AI-88

`DECISIONS_AI_0921_vlm_executable.md`.

VLM 의 역할을 **스킬 선택 → 실행 전 판정(grounding)** 으로 바꿨다.

```
질문   "지금 이 장면에서 이 스킬을 실행할 수 있는가"
출력   2지선다 (불가 / 가능) · chance 0.20 → 0.50
게이트 빈 장면 거부율 ≥ 0.90 · 오거부율 ≤ 0.10 · 정확도 ≥ 0.85
```

`AI/vlm/executable.py` (19/19). `skill_choice.py` 가 모듈 최상단에서 torch 를 import 해서
**ast 로 소스만 파싱해** SKILLS/SKILL_KO 를 읽는다.

둘러보기(active scanning): `scan_decision(frame_verdicts, k)` · `choose_k(scans, n_frames)` —
오거부율 0.10 이하인 k 중 거부율이 최대인 것을 고르고, 없으면 None 을 돌려준다.

⚠️ **실제 모델 측정 미실행.** 설계와 게이트만 있다.
