## Problem — 어시스턴트 오류

- r23 을 "위치 규칙으로 놓았다" 고 말했다. 패치는 젯슨에 적용조차 안 돼 있었다(grep 0). **확인 없이 단정** — 사용자가 로그를 요구해서야 드러남
- release 기준 250틱을 데이터 없이 정했다 → r20 이 0.7mm 차이로 안 놓음
- squeeze 패치에 "정책이 열어도 안 열림" 을 PASS 로 넣었다 — 놓기를 설계로 막음 (9/25)
- hold-floor 를 '래치' 에 걸었다 → 열린 채 래치가 걸려 잡기 전에 상승 (r5). ramp 50mm → 쥐자마자 +45mm 명령으로 과부하 기여 (r6)
- hold-floor ramp 를 관측 z 기준으로 설계 → 팔이 처지면 바닥도 같이 내려감. r23 성공이 이 허점에 기댔을 가능성
- r9 후 "floor 가 원인, 확정" → r10(floor 0)에서 같은 0x20. 틀림
- "전류 클 때만 깨진다" 가설 → 정지 토크 OFF 12.5% 실패로 기각. "3.4% 면 재시도 8회로 충분" → 실패가 몰려서 옴(8연속)
- 새 모터 영점 차이를 눈대중 수평 재저장으로 풀려 했다 (r15·r18 두 번 실패)
- 명령 실수: 패치 경로 runtime_jt/ (실제 …/umi_checkpoint_executor/), --help 에 LD_LIBRARY_PATH 누락, grep 기대값 3 (실제 6), 로컬/젯슨 창 구분 없는 scp
- r4 이후 서보 온도를 안 보고 연속 실행 → 2번 45°C
- 젯슨 로그를 못 읽는데 "로그 봐바" 에 매번 명령만 되돌려 줬다 — 처음부터 로그 파일을 Downloads 로 끌어오는 경로를 깔았어야 했다
- 사용자 불만: 제약이 너무 많다. 안전과 무관한 확인 단계까지 매번 끼워 넣었다
