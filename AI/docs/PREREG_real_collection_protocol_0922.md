# PREREG — 실물 시연 수집 프로토콜 (2026-09-22 실물 세션에서 역산)

작성자: 김준태(트랙 B) · 수집 전 사전등록 · **수집 시작 전 트랙 A 합의 필요**

> 오늘 실물 로봇에서 실패한 것들을 실행부에서 고치려다 대부분 **데이터 쪽 문제**로
> 판명됐다. 그 역산 결과가 이 문서다. 게이트와 예측을 수집 **전에** 박는다.

---

## 0. 한 줄

**정책은 시연에서 본 것만 한다.** 오늘 실물에서 정책이 못 한 세 가지(측면 보정 ·
접근 중 개구 유지 · 물체 폭까지 폐쇄)는 전부 **시연에 그 행동이 없었기 때문**이다.
수집 프로토콜이 곧 정책의 능력 상한이다.

---

## 1. 오늘 실물에서 확정된 것 — 수집에 직접 영향 🟢

측정 조건: SO-101 실물 · pv_E 체크포인트 · `runtime_jt` 포크 · 물체 41mm 구운감자 ·
`--settle-timeout 6.0 --settle-tolerance 5 --settle-retries 3`

### 1-1. 측면 상수 편향 약 15mm 🟢

물체를 걸린 손가락 반대 방향으로 **15mm** 옮기자 정책이 원하는 위치까지 정확히 갔다.
그 전까지는 매번 **같은 쪽 손가락**에 걸렸다 — 무작위 실패면 방향이 섞인다.

→ 프로젝트 기록의 *"hand-eye 오차는 상수 편향이라 학습이 지우지 못한다"* 가 실물에서 재확인됐다.
→ **수집 전에 camera-TCP 보정을 다시 잡지 않으면, 수집한 데이터에 그 편향이 그대로 구워진다.**

### 1-2. 접근 중 측면 보정 능력이 없다 🟢

접근 구간(c0~c7) 명령 Δy 실측: `+2.6 −3.6 +0.4 +2.4 −1.0 +1.5 +2.1 −1.5` — **부호가 계속
뒤집히는 잡음**이다. 크기 1~4mm. 같은 구간 Δx 는 `+9.8 → +2.6` 으로 단조 수렴한다.

즉 정책은 **전진만 하고 좌우 보정을 안 한다.** 물체가 옆으로 틀어져 있으면 그대로 민다.

→ 원인 추정 🟡: 시연에서 물체가 늘 같은 자리에 있었다면 **보정할 일이 없었으므로 배우지 못한다.**
   **미검증** — 기존 시연의 물체 위치 분산을 아직 안 쟀다. **수집 전에 반드시 측정한다.**

### 1-3. 그리퍼 폭은 정책의 위상 신호다 🟢

그리퍼 명령을 특정 폭에 고정하면 **정책 전체가 망가진다.** 2/2 실패:

```
78.97mm 고정 → 래치 안 걸림, 팔이 물체를 지나쳐 계속 전진
70.70mm 고정 → 동일
```

그리퍼를 안 닫으면 정책은 "아직 파지 단계가 아니다"로 판단하고 접근을 멈추지 않는다.

→ **시연에서 다가가며 닫는 그 프로파일 자체가 학습된다.** 시연자마다 닫는 시점·속도가
   다르면 위상 신호가 흐려진다. **닫는 방식을 통일해야 한다.**

### 1-4. 정책의 최종 폐쇄 폭이 물체보다 약 5mm 넓다 🟢

위치를 맞춘 런에서 정책 수렴값 `predicted_gripper_mm 43.0`, 물체 41mm → **빠진다.**

→ 시연에서 **물체에 닿을 때까지 확실히 조이지 않으면** 그 여유가 그대로 학습된다.
→ 실행부 보정으로 덮으려 했으나(아래 1-5) 그건 임시방편이다. **수집에서 잡아야 한다.**

### 1-5. 절대 목표에 상수를 더하면 복리로 닫힌다 🟢

`--gripper-close-offset-ticks` 는 **절대** 그리퍼 목표에 N틱을 더하고, 정책은 그 결과 관측에
앵커해 다음 명령을 낸다. 그래서 **매 사이클 N틱씩 닫힌다.** N=91(5mm) 실측:

```
c0 정책 330 → 목표 421 (73.9mm)     c3 정책 631 → 목표 722 (57.5mm)
c1 정책 431 → 목표 522 (68.3mm)     c4 정책 863 → 목표 954 (44.6mm)
c2 정책 531 → 목표 622 (62.9mm)     c5 정책 1030 → 목표 1121 (35.3mm)
```

정책은 사이클당 **+10틱**(= 현상 유지)만 명령했다. 닫은 건 전부 오프셋이다.
c5 에 이미 다 닫혔고 그때 x=345 로 **도착(372) 전**이었다.

→ **`--gripper-close-offset-ticks 0` 고정.** 수집·재생·평가 전부.

### 1-6. 실행부는 이제 문제가 아니다 🟢

settle 잔차 재명령으로 z 오차가 청크당 **−16.4mm → −1~−3mm**. 리프트 구간
(z 138→205.7mm)에서도 err −1.0~−4.2mm 로 유지됐다.

→ 수집한 데이터가 좋으면 실행부가 깎아먹지는 않는다. **병목은 데이터다.**

## 2. 수집 프로토콜

### 2-A. 수집 시작 전 — 하나라도 빠지면 수집 금지

| # | 항목 | 판정 기준 | 근거 |
|---|---|---|---|
| A1 | camera-TCP 보정 재측정 | 재생 오차 중앙 **≤ 5mm**, 편향(부호 일관성) 없음 | 1-1 |
| A2 | 이미지–액션 타임스탬프 동기화 계측 | 지연 중앙과 분산을 수치로 기록 | 프로젝트 지침 · ARCore 전환 |
| A3 | 물체 치수·질량 실측 | 폭·높이·질량 기록. **시뮬 스펙 전이 금지** | 1-4 · 오늘 캔 가정 오류 |
| A4 | 기존 시연의 물체 위치 분산 측정 | x·y 표준편차를 수치로 | 1-2 (현재 **미검증**) |
| A5 | 그리퍼 시작 개구 규약 확정 | 단일 값 ±3mm | 1-3 · 오늘 런마다 달랐다 |

**A4 가 이 문서의 핵심 미검증 항목이다.** 기존 시연의 물체 위치가 이미 흩어져 있는데도
정책이 보정을 못 한다면 원인이 다른 데 있다. 먼저 재고 수집 설계를 정한다.

### 2-B. 수집 중 — 시연자 규약

```
1. 물체 위치를 의도적으로 흩는다
     좌우 ±30mm · 전후 ±20mm · 회전 ±20°  (격자 아니라 매 편 무작위)
     "환경은 다양하게, 시연 방식은 동일하게" 의 '환경' 이 이것이다

2. 시작 개구를 고정한다
     매 편 같은 값에서 시작. A5 에서 정한 값

3. 닫는 방식을 통일한다
     다가가며 닫는 프로파일을 시연자 전원이 동일하게
     "접근 완료 후 한 번에" 든 "다가가며 점진" 이든 하나로 정하고 끝까지 지킨다
     ※ 정책은 이 프로파일을 위상 신호로 쓴다 (1-3)

4. 물체에 닿을 때까지 확실히 조인다
     손가락이 물체에 접촉해 저항이 생기는 지점까지. 여유를 남기지 않는다 (1-4)

5. 속도를 일정하게, 그리고 느리게
     실행부는 청크 16스텝 중 4스텝만 실행하고 settle 을 기다린다.
     시연이 빠르면 첫 4스텝의 이동량이 과해진다

6. 파지 순간 전후를 중요하게 다룬다
     제품 기조: 결과 모방이지 궤적 모방이 아니다.
     접근 경로는 요란해도 되지만 파지 순간은 깨끗해야 한다
```

### 2-C. 단계식 수집 — 프로젝트 규약 그대로

```
20편 → 검증 → 프로토콜 확정 → 100편 → 게이트 → 나머지
```

20편 시점 검증 항목: 물체 위치 분산이 의도대로 나왔는지 · 시작 개구 편차 ·
폐쇄 프로파일 일관성 · 타임스탬프 동기화. **모수 병기 필수** (`통과 18 / 전체 20`).

## 3. 사전 등록 — 결과 보기 전에 박는다

**가설 H1**: 물체 위치를 흩어서 수집하면 정책이 접근 중 측면 보정을 학습한다.

**판정 지표**: 접근 구간(파지 전 청크들) 명령 `Δy` 의
**물체 측면 오프셋과의 상관계수**. 잡음이면 0 근처, 보정을 배우면 유의하게 음/양.

**참조 집단**: 오늘 pv_E 실측 — 접근 구간 Δy 부호 반전 7/7, 크기 1~4mm, 상관 **미측정**.
새 정책이 이보다 나으면 학습된 것으로 본다.

**게이트**:

| 항목 | 기준 |
|---|---|
| 측면 오프셋 ±20mm 배치에서 파지 성공 | ≥ 70% (n ≥ 20) |
| 정위치 파지 성공 | ≥ 90% (n ≥ 20) |
| 최종 폐쇄 폭 − 물체 폭 | 중앙 **≤ 0mm** (물체를 물어야 한다) |

**게이트를 못 맞추면 게이트를 낮추지 않는다. 수집 편수를 늘리거나 프로토콜을 고친다.**
